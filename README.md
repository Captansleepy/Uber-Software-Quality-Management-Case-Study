# Software Quality Management – Uber Case Study

## Quality Policy
The objective of this project is to ensure that the Uber software system delivers reliable, secure, and high-performance services to users. The quality management process focuses on defect prevention, risk control, and continuous quality improvement.

## Quality Standards and Models
This project follows recognized software quality frameworks:
- ISO/IEC 25010 Software Quality Model
- Capability Maturity Model Integration (CMMI)

## Key Quality Attributes
The key quality attributes considered in this project include:
- Reliability
- Performance Efficiency
- Security
- Usability
- Functional Suitability

## Quality Management Approach
- Defects and risks are recorded and managed using GitHub Issues.
- Severity, priority, and root cause are identified for each defect.
- A GitHub Project Board (Kanban) is used to track progress.
- Labels are used to ensure classification and traceability.
- All quality-related activities are traceable through issues and project workflows.
